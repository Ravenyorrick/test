# Release

Production release requires:

- Passing automated tests.
- Manual launch verification on Windows and macOS.
- Signed Windows installer and virtual audio driver.
- Signed/notarized macOS app and virtual audio component.
- Complete third-party and model license review.
- Driver rollback and recovery documentation.

Phase 1 is not release-ready for end users because core native audio, voice conversion, and virtual microphone features are not implemented.
