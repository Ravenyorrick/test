# macOS

Target platforms: Apple Silicon and Intel macOS where the required virtual audio architecture is technically supported.

## Production requirements

- `.dmg` distribution.
- Microphone permissions.
- Signed and notarized app bundle.
- Signed/notarized virtual audio component.
- Sleep/wake and device-reset recovery.

## Current status

Phase 1 configures the Electron app and `.dmg` target only. macOS virtual audio implementation is not present yet.
