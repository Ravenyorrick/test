# Windows

Target platforms: Windows 10/11 where the required virtual audio driver architecture is technically supported.

## Production requirements

- `.exe` installer.
- Application icon and uninstaller.
- Signed application binaries.
- Signed virtual microphone driver package.
- Driver install, repair, remove, restart, and test workflows.

## Current status

Phase 1 configures the Electron app and installer target only. Windows driver implementation is not present yet.
