# Third-Party Licenses

This file tracks dependencies and licensing obligations before production distribution.

## Application dependencies

- Electron
- React
- Vite
- TypeScript
- electron-builder
- Vitest
- Testing Library

Review installed package licenses from `package-lock.json` before release.

## Voice models and providers

No voice model assets are included in Phase 1. Built-in voice entries are metadata placeholders for future properly licensed downloadable/provider-backed models and must not be shipped as functional voices until licensing is complete.

## Native audio and virtual device components

Native library, driver, and platform SDK licensing must be documented when those components are added.
